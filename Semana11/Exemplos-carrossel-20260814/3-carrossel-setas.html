Carrossel com setas de navegação

Mesmo carrossel com scroll-snap, agora com botões de "anterior" e "próximo" controlados por um pouquinho de JavaScript.
const trilho = document.querySelector('.carrossel'); document.querySelector('.next').onclick = () => { trilho.scrollBy({ left: 280, behavior: 'smooth' }); }; document.querySelector('.prev').onclick = () => { trilho.scrollBy({ left: -280, behavior: 'smooth' }); };
