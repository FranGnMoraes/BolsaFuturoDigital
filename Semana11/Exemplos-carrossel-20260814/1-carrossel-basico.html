Carrossel básico com Flexbox

display: flex organiza as fotos lado a lado; overflow-x: auto libera a rolagem horizontal quando elas não cabem.
↔ Arraste a barra de rolagem (ou use o scroll do mouse/trackpad) para navegar pelas fotos.
.carrossel { display: flex; gap: 16px; overflow-x: auto; } .foto { flex: 0 0 220px; /* largura fixa, não cresce nem encolhe */ height: 150px; }
