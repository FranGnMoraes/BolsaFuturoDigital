Somar a lista

loops (percorrer + acumular)

Objetivo

Percorra um array com um loop para somar valores e contar quantos passam de um limite.

Passo a passo

  1. Percorra o array numeros com um loop (for ou forEach).
  2. Acumule a soma de todos os valores em soma.
  3. Conte em maioresQue25 quantos números são maiores que 25.
💡 Dica: Comece soma = 0 e maioresQue25 = 0 ANTES do loop. Dentro, faça soma += n e, com um if, maioresQue25++ quando n > 25.
