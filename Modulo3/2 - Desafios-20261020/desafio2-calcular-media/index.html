Calcular a média

funções (parâmetros e return)

Objetivo

Crie uma função que recebe três notas e devolve a média delas.

Passo a passo

  1. Complete a função media(a, b, c).
  2. Some os três valores e divida por 3.
  3. Use return para devolver o resultado (não use console.log dentro da função).
💡 Dica: A média é (a + b + c) / 3. Lembre dos parênteses: a soma acontece antes da divisão. O return entrega o valor para quem chamou.
