Classificar a nota

condicionais (if / else if / else)

Objetivo

Complete a função que devolve a situação do aluno a partir da nota.

Passo a passo

  1. A função situacao(nota) já está criada — complete o corpo dela.
  2. Devolva "Excelente" se a nota for 9 ou mais.
  3. Devolva "Aprovado" se for 6 ou mais (e menor que 9).
  4. Caso contrário, devolva "Recuperação".
💡 Dica: Use if, else if e else com return em cada ramo. Teste do maior para o menor: o JS para no primeiro que der verdadeiro.
