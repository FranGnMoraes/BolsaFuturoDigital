juntando tudo: submit + value + criar + limpar

Objetivo

Ao enviar, adicione a tarefa digitada na lista e limpe o campo.

Passo a passo

  1. No "submit", chame event.preventDefault().
  2. Crie um <li> com o value do campo e anexe em #lista.
  3. Depois, limpe o campo com nova.value = "".
💡 Dica: Junta tudo: preventDefault → createElement("li") → li.textContent = nova.value → lista.append(li) → nova.value = "".
