Validar o campo

submit + condicional

Objetivo

Ao enviar: se o campo estiver vazio, mostre um erro; senão, mostre sucesso.

Passo a passo

  1. No "submit", chame event.preventDefault().
  2. Se email.value === "", ponha em #aviso o texto "Preencha o campo!".
  3. Senão, ponha "Cadastrado!".
💡 Dica: É uma condicional: if (email.value === "") { ... } else { ... }. Lembre do preventDefault() antes.
